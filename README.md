# Global Economy MC Test Practice

A static, mobile-friendly quiz website based on the three uploaded English lecture notes.

## What's included
- 60 original multiple-choice questions (20 per lecture)
- Choose one lecture at a time
- Full 20-question practice or random 10 / random 5
- Instant feedback and explanations
- Final score and review of every answer
- No dependencies, no build step, no backend

## Run locally
Open `index.html` in a web browser.

## Publish on GitHub Pages
1. Sign in to GitHub and create a **new public repository**, e.g. `global-economy-mc-quiz`.
2. Upload `index.html` and `README.md` to the repository's root (or upload the contents of this ZIP).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. The URL will appear in the Pages settings, usually `https://YOUR-USERNAME.github.io/global-economy-mc-quiz/`.

This package is ready for GitHub Pages, but it has not been uploaded to a GitHub account automatically.
